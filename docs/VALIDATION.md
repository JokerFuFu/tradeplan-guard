# v0.3 本地版本验证记录

验证日期：2026-10-28。当前产品只包含 Skill 和独立策略机器人。

- Python 完整测试套件 50 项通过；保留行情、数量计算、订单预览、虚拟账本与策略限制测试，新增 8 项独立机器人 CLI 测试。
- CLI 验证覆盖跨目录调用、样例不创建账本、暂停创建、启动与单轮执行、暂停/停止、订单与事件查询、价格条件、异常配置/账本路径、前台进程 Ctrl+C 退出及持久化。
- Skill 元数据校验通过。机器人引擎原样迁移到 Skill 内，SQLite 数据结构未变；项目入口与独立 Skill 入口可通过同一显式 --db 共享账本。
- 当前源码已移除网页、HTTP 服务和独立语言模型接口；旧 v0.2 压缩包保留用于恢复。机器人不监听端口，不安装系统定时任务。
- 测试使用独立临时数据库。测试期间没有访问真实账户、发送欧易订单或提交申请。

本地虚拟资金与交易所模拟盘、实盘不同。Builder Code 仍为空，机器人尚未实现交易所订单执行与归因，不能产生手续费分成。此前已验证的公共行情客户端保留，本次范围调整未新增账户或网络调用。

## 重现

```bash
python3 -m unittest discover -s tests -v
python3 bot.py sample
python3 bot.py --help
python3 skills/okx-tradeplan-guard/scripts/tradeplan.py demo
```

完整机器人生命周期见 [机器人快速开始](BOT-QUICKSTART.md)。运行机器人时明确指定持久化账本，并核对配置；关闭前台进程会停止检查，但保留策略运行状态。
